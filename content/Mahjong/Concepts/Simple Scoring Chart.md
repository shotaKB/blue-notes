I tried to simplify the mahjong scoring system as much as possible here. Just base everything off of your hand and the number of hans. I still don't understand hu but I get by without them.

## Non-Dealer (Ko)

|                        |    1    |    2     |     3     |     4     |
| :--------------------: | :-----: | :------: | :-------: | :-------: |
|      Pinfu, Tsumo      |    -    | 400/700  | 700/1300  | 1300/2600 |
|       Pinfu, Ron       |  1000   |   2000   |   3900    |  Mangan   |
|    No Pinfu, Tsumo     | 300/500 | 500/1000 | 1000/2000 |  Mangan   |
|  No Pinfu, Ron (Open)  |  1000   |   2000   |   3900    |  Mangan   |
| No Pinfu, Ron (Closed) |  1300   |   2600   |   5200    |  Mangan   |

## Dealer (Oya)

|                        |    1    |    2     |    3     |    4     |
| :--------------------: | :-----: | :------: | :------: | :------: |
|      Pinfu, Tsumo      |    -    | 700 all  | 1300 all | 2600 all |
|       Pinfu, Ron       |  1500   |   2900   |   5800   |  Mangan  |
|    No Pinfu, Tsumo     | 500 all | 1000 all | 2000 all |  Mangan  |
|  No Pinfu, Ron (Open)  |  1500   |   2900   |   5800   |  Mangan  |
| No Pinfu, Ron (Closed) |  2000   |   3900   |   7700   |  Mangan  |

## Mangan and Above

|     Han     |     Name      | Non-Dealer | Dealer |
| :---------: | :-----------: | :--------: | :----: |
|     4-5     |    Mangan     |    8000    | 12000  |
|     6-7     |    Haneman    |   12000    | 18000  |
|    8-10     |    Baiman     |   16000    | 24000  |
|    11-12    |   Sanbaiman   |   24000    | 36000  |
| 13+/Yakuman | Kazoe/Yakuman |   32000    | 48000  |

That's it! This works 98% of the time, the only times you might have a different score is if you kanned, or have an yakuhai anko. Note that in online mahjong like Mahjong Soul some 4 han scores are reduced slightly, for example 4 han Pinfu + ron is actually 7700, but it's a negligible difference.

If you have a little more time to spare I suggest learning chiitoitsu as well.

## Chiitoitsu

|                   |  1  |  2   |    3     |     4     |   5    |
| :---------------: | :-: | :--: | :------: | :-------: | :----: |
|  Non-Dealer, Ron  |  -  | 1600 |   3200   |   6400    | Mangan |
| Non-Dealer, Tsumo |  -  |  -   | 800/1600 | 1600/3200 | Mangan |
|    Dealer, Ron    |  -  | 2400 |   4800   |   9600    | Mangan |
|   Dealer, Tsumo   |  -  |  -   | 1600 all | 3200 all  | Mangan |

Chiitoitsu has 2 han by itself so the 1 han scores don't exist. Open/Closed also doesn't matter as you can only get chiitoitsu as a menzen hand.
